Completionist v0.1.0 - FOUNDATION BUILD, NOT FULL QUEST AUDIT
Requires the separate QuestieDB Vanilla package (not the Questie guide UI).
Install QuestieDB and Completionist folders into Interface/AddOns in WoW Classic Era.
/comp opens the window; /comp exploration, /comp discovery, /comp audit change modes.
/comp zone <mapID> manually inspects a map's quest catalog.

IMPORTANT LIMITATIONS
QuestieDB zoneOrSort is a zone classification, not independently verified origin attribution.
Subzones, map highlighting, full prereq/profession/reputation gating, reliable repeatable/donation classifications and first-login historic-completion import are NOT finished.
The initial build intentionally displays unverified status and does not award misleading completion percentages for unverified quests.
Quest completion events and turn-in counts are tracked going forward; QuestieDB provides quest IDs at runtime.
