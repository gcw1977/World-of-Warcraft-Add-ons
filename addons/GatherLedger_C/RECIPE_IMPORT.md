# GatherLedger Recipe Import v0.6.2

Recipe import is now a compact, Classic-styled panel physically attached below the profession window. It follows the window and hides when the profession window closes.

- Craft count and Add Reagents retain their v0.6.1 behavior.
- No changes to saved data, shopping list, inventory snapshots or the gathering collector.
- The controls are outside Blizzard's clickable profession content.

Test with Leatherworking and Cooking, including moving and closing each profession window. This build has been structurally checked, but cannot be runtime-tested without the WoW Classic client.
