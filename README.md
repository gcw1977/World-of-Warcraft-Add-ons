# Beestwood Industries — World of Warcraft Add-ons

This is the public source-inspection repository for **Beestwood Industries** World of Warcraft addons.

## Publication status

**Source publication is being verified.** This repository currently contains project information and usage terms; no addon source package is represented as a tested or approved public release merely because it exists in a private development archive.

When a version has been cleared for publication, its readable Lua, `.toc`, and other redistributable source files will appear in an addon-specific directory. Release archives may also be provided. Public visibility does **not** imply that a build has passed in-game testing.

## Access and permitted use

Published addon releases are intended to be available **free of charge** for personal, noncommercial gameplay. Individuals may download and run an **unmodified** published release for that purpose, subject to the [LICENSE](LICENSE). Public source visibility is for inspection; this is **not an open-source license**. Commercial reuse, redistribution, and publication of modified versions require separate written permission.

Do not assume that third-party libraries, assets, or dependencies are included or sublicensed. Their owners retain their own rights.
