# Beestwood Industries — World of Warcraft Add-ons

This is the public source-inspection repository for **Beestwood Industries** World of Warcraft addons.

## Available source snapshots

**Seven addon source archives are now publicly accessible in [sources/](sources/).** Each ZIP contains its corresponding addon source files (including Lua and `.toc`). These are **development snapshots**, not gameplay-tested, stable, or release-approved builds. See [source status and versions](sources/STATUS.md).

For convenient inspection, download and extract the ZIP associated with the addon of interest. The packages have not yet been expanded into individually browsable source directories in this repository.

PackMate 0.3.1 is expressly **PENDING / UNTESTED**. The Completionist archive references an external QuestieDB dependency; Questie code is not bundled.
