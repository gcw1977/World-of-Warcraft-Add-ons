# Beestwood Industries — World of Warcraft Add-ons

This is the public source-inspection repository for **Beestwood Industries** World of Warcraft addons.

## Available source snapshots

**Seven addons now have directly browsable Lua, TOC, and documentation files in [addons/](addons/).** The matching original ZIP snapshots remain available in [sources/](sources/). These are **development snapshots**, not gameplay-tested, stable, or release-approved builds. See [source status and versions](sources/STATUS.md).

Browse each addon directory directly to inspect its files, or download the original ZIP snapshot.

PackMate 0.3.1 is expressly **PENDING / UNTESTED**. The Completionist archive references an external QuestieDB dependency; Questie code is not bundled.
